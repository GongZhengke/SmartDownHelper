# 智慧视频下载器

一个 Windows 图形界面小工具，输入视频网址即可下载视频并转成 MP4。

> 对应程序：`SmartDown.exe`（单文件、免安装、已内置 ffmpeg）

## 功能

- 输入**视频网页网址**，自动定位并解析出视频的 m3u8 播放列表
- 支持直接输入 `.m3u8` 地址（自动识别 master 列表并选最高码率）
- 多线程并发下载分片，带**进度条**与实时日志
- 可选择**保存目录**、**保存文件名**
- 可选择**清晰度**（最高 / 1080p / 720p / 480p / 360p）
- 下载完成后自动用 ffmpeg **无损合并成 MP4**（失败时自动重编码兜底）
- 支持**高分屏**（自动启用 DPI 感知）

## 支持网址

### 1. GJ中小学智慧教育平台课程详情页

例如教师研修类课程页面：

```
https://basic.smart***.cn/teacherTraining/courseDetail?courseId=...
```

原理：从网址解析 `courseId` → 调用课程接口拿到 `activity_set_id` → 调用活动接口拿到视频的 m3u8 地址（含多线路、多清晰度），然后下载。

### 2. 直接 m3u8 地址

```
https://xxx/xxx/xxx.m3u8
```

## 使用方法

1. 双击 `智慧视频下载器.exe` 打开程序
2. 在「视频网址」框粘贴网址
3. （可选）选择「清晰度」
4. 点击「保存目录」旁的 **浏览...** 选择保存位置
5. 点击「保存文件名」旁的 **浏览...** 选择文件名，或留空自动按视频标题命名
6. 点击 **开始下载**
7. 等待进度条走完，日志显示「已保存」即可

> 一个课程里若有多个视频，程序会自动逐个下载，文件名自动加序号区分。

## 运行环境

- 系统：Windows 10 / 11（64 位）
- **无需**安装 Python、无需单独安装 ffmpeg（已内置）

## 常见问题

**Q：下载到一半失败？**
点击「取消」后重新「开始下载」即可；程序会重试，断网恢复后一般能续上（分片重新下载）。

**Q：提示「未找到 ffmpeg」？**
正常情况下不会出现（ffmpeg 已打包进 exe）。若在源码方式运行时出现，执行 `pip install imageio-ffmpeg` 或安装系统 ffmpeg。

**Q：为什么网页打不开、找不到视频？**
仅支持上述两类网址；需保证网络能访问 `*.ykt.cb***.com.cn` / `*.smart***.cn`。
